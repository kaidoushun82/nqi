# NQI - Not Qmage Image

NQI (short for Not Qmage Image) is an image format that aims to acheive similar-level (or better) compression of images as Qmage A9LL, whilst adding more features that Qmage lacks thereof, like 24-bit RGB output.

# Current status

This project has not begun work yet; at the moment it's in the planning stage.
