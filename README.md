# NQI - Not Qmage Image

NQI (short for Not Qmage Image) is an image format that aims to acheive similar-level (or better) compression of images as Qmage A9LL, whilst adding more features that Qmage lacks thereof, like full color 24-bit RGB output, along with block-level pixel run-length and offset to save on palette data buffer size.

# Building

This project can be built with help of CMake.
